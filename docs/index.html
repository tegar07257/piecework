PieceWork

Milestone escrow for freelance work on Tari Ootle.

This page is a simulation. It mirrors, rule for rule, the PieceWork Rust template for the Tari Ootle engine that lives in this repository (src/lib.rs), and it runs entirely in your browser with pretend balances. There is no wallet, no network and no real TARI involved. The on-chain artifact is the template plus its engine tests (cargo test); this page is the judge path — the quickest way to see exactly what the template allows and what it rejects. The template has not been published to any network.
